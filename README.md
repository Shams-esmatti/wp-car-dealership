# 🏎️ WordPress Car Dealership Engine

A custom-built WordPress project demonstrating professional architecture, data modeling, and performance optimization.

## 🛠️ Tech Stack

- **OS:** Ubuntu (Linux)
- **Local Env:** LocalWP
- **Core:** WordPress (PHP)
- **Architecture:** Separation of Concerns (Custom Plugin for Logic, Custom Theme for View)

## 🚀 Key Features

- **Custom Post Type:** Dedicated 'Cars' entity built from scratch (no plugins like ACF used).
- **Data Modeling:** Custom Meta Fields for Price management.
- **Taxonomies:** Organized by Brands/Manufacturers.
- **Frontend:** Optimized PHP Loop with CSS Grid for a high-performance showroom gallery.

## 📁 Project Structure

- `/plugins/car-collection-engine`: The 'Engine' - handles CPT and Meta logic.
- `/themes/car-showroom-theme`: The 'Showroom' - handles the UI and templates.
